# Asypy

Astrophysics simulations and experiment reports.

## Orbit experiments

The [Euler-Cromer Experiment](Euler-Cromer%20Experiment/README.md) folder contains the simulation code, two reports, plots, and CSV data for orbit shape and conservation experiments. Its README explains setup and how to reproduce the results.

The folder name is the experiment label; the current numerical integrator is velocity Verlet, as documented inside the project.

## Integrator comparison

The [Integrator Comparison Experiment](Integrator%20Comparison%20Experiment/README.md) is a separate, self-contained experiment comparing forward Euler, Euler-Cromer, and leapfrog. It includes period, apsis-speed, and swept-area checks.
